# FinTrack

Fintrack is a modern and adaptable UI kit built for finance management and digital wallet applications. It helps users stay in control of their money tracking expenses, managing transactions, and viewing financial insights through an intuitive and visually consistent interface.

#  Create a repository in Git 
   
   Clone the Repo - git clone https://github.com/srinandhinimca/FinTrack.git

   cd Fintrack

   Git init

 # Create Project in Expo Dev

   i. npm install --global eas-cli

   ii. npx create-expo-app@latest . 

   iii.choose the current SDK

   iv.eas init --id 8916ebe8-ac07-4371-9e38-633316125ef8
